1重启后持久化

每次加载自动写入：localStorage 随机 token + 访问计数、一个 Cookie、以及 Canvas 指纹哈希。 操作步骤：记下下方数值 → 完全杀掉 App（从最近任务划掉）→ 重新启动 → 打开本页 → 各数值应保持一致且访问计数 +1。 若 Cookie 永远显示缺失，请检查 CookieManager.setAcceptCookie(true) 与 cacheMode 设置。 若 token 均正常但指纹变化，说明该设备 GPU/Canvas 不具备确定性（属提示信息，不算失败）。

2NativeApp JS 桥接

验证 addJavascriptInterface(..., "NativeApp")。桥接对象必须存在，且包含 setColor(r,g,b) 与 closeWebView() 两个方法。
人工核对：调用 setColor 后，由 Native 侧管理的安全区/状态栏填充色必须立即切换为上方的精确 RGB 值。逐个点击预设色验证切换是否即时生效。
预期：隐私确认页关闭。在非隐私页调用可能直接关闭 Activity，请谨慎使用。
